你是电网运维知识图谱抽取器。下面是同一篇运维文档中编号为 [1]、[2]… 的若干文本块，请从中抽取结构化三元组 (主体, 关系, 客体)。

【实体类型】只抽这些类型的名词短语作为主体/客体：{entity_types}（设备如主变压器/断路器/隔离开关/互感器/避雷器/电缆/母线/GIS 等）。

【关系白名单】关系 r 只能从以下选一个；文本中不属于这些语义的【不要抽】：
{relations}

【严格要求】
1) 只抽文本中明确出现的事实，绝不编造。
2) 主体 s 与客体 o 使用文本中的原文写法，必须是具体名词短语（设备名/现象/措施/参数），不得是章节号、"本文""本章"等泛指词。
3) s_type、o_type 取自实体类型列表；r 必须在白名单内。
4) chunk_no 填写该事实所在文本块的编号（整数）。
5) 输出严格 JSON 数组：[{{"s":"主体","r":"关系","o":"客体","s_type":"类型","o_type":"类型","chunk_no":1}}, ...]；无合适三元组输出 []。不要解释、不要 markdown 代码块。

【好例】
文本：[1] 主变压器上层油温超过 95℃，应立即减负荷运行并检查冷却系统。
输出：[{{"s":"主变压器","r":"预警阈值","o":"上层油温95℃","s_type":"设备","o_type":"运行参数","chunk_no":1}},{{"s":"主变压器","r":"处置方法","o":"减负荷运行","s_type":"设备","o_type":"处置措施","chunk_no":1}}]

【坏例（禁止）】

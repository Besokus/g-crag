# 通用化采用"核心链路 + 可插拔领域包"，不做无 schema 抽取

通用化 grid-qa 时，没有把图谱改成无 schema 的自由抽取，而是把实体类型、关系白名单、归一化规则、术语表、领域措辞、种子语料抽成可插拔的领域包，电网作为第一个领域包保留。主要原因是 G-CRAG 的纠错要沿图谱扩展邻居，无 schema 抽取得到的图谱实体重复、关系混乱，纠错效果无法体现；其次，保留电网领域包可以复现原 grid-qa 的行为，方便复盘和作为对照基线。

## Consequences

- 领域可配置的方式是"核心提供策略、领域包选择策略并提供数据"：核心链路在需要领域知识处定义扩展点并实现通用策略，领域包只用配置选策略、配参数。某领域需要新策略时，把它作为通用策略加入核心，领域包永远不带代码。

## Considered Options

- 彻底去领域化 + 无 schema 抽取：改动最少，但图谱噪声大，会削弱本项目的核心创新点。

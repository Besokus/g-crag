# 三元组关联到出处 chunk：批量抽取时由 LLM 标序号，再用字符串校验兜底

图谱定位证据需要从图谱关系回到原文段落，而 grid-qa 的三元组只关联 `doc_id`（6 个 chunk 一批抽取，出处在抽取时即丢失）。我们保持批量抽取，让 LLM 为每条三元组标注出自批内第几个 chunk；随后校验主语、宾语（含领域包别名）是否出现在该 chunk 中，不符则在同批内按字符串重找，仍找不到则该三元组只保留文档级关联、不参与图谱定位证据。宁可少用一条关系，也不引入错误证据。

## Considered Options

- 逐 chunk 单独抽取：出处精确，但 LLM 成本约 6 倍，且会漏掉跨段落关系。
- 不改抽取、事后字符串匹配：零成本，但实体经过归一化后与原文写法对不上，准确度低。

## Consequences

- `KgTriple` 与 Neo4j 关系需新增 `chunk_id` 属性，现有图谱需重建。
